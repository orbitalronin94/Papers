Resumen del problema

Hill Equation — Degeneración K–n_H

En el régimen sub-saturado (Ω ≪ K), los parámetros K y n_H son estructuralmente no identificables. Los datos solo identifican la constante combinada A = K−n_H.

Condición: 1.22e+16 Params: K, n_H

PBPK — Degeneración Vt–Kp

Sin datos tisulares, el volumen tisular Vt y el coeficiente de partición Kp son estructuralmente no identificables. Solo aparecen como el producto Vt · Kp.

Condición: 1.15e+11 Params: Vt, Kp

Del diagnóstico que precede al ajuste: Ajustar sin diagnosticar es como construir sin planos. Puedes hacerlo, pero el edificio se caerá. Diagnosticar primero es saber si el edificio es posible antes de poner la primera piedra.

Proposición 5.1 — Degeneración asintótica

Si Ω ≪ min(K₁, K₂), la función Hill satisface:

H(Ω; K₁, α₁) ≈ H(Ω; K₂, α₂)

siempre que α₁ log Ω − α₁ log K₁ = α₂ log Ω − α₂ log K₂. El término dominante es A · Ω^α con A = K^(−α).

Diagnóstico PBPK (Python)

"""
pbpk_identifiability.py — Diagnostic protocol for non-identifiability in PBPK models.

Author: David Ferrandez Canalis — Agencia RONIN
License: CC BY-NC-SA 4.0 + Cláusula Comercial Ronin
"""

import numpy as np
from scipy.integrate import solve_ivp
from dataclasses import dataclass
from typing import Dict, List, Optional


@dataclass
class PBPKModel:
    CL: float = 0.5
    Vp: float = 3.0
    Q: float = 5.0
    Vt: float = 15.0
    Kp: float = 2.0
    kon: float = 0.1
    koff: float = 0.05
    R0: float = 10.0
    kint: float = 0.1
    kdeg: float = 0.01

    @property
    def parameter_names(self) -> List[str]:
        return ["CL", "Vp", "Q", "Vt", "Kp", "kon", "koff", "R0", "kint", "kdeg"]

    def simulate(self, t_eval: np.ndarray, dose: float = 100.0):
        y0 = np.array([dose / self.Vp, 0.0, self.R0, 0.0])
        sol = solve_ivp(self.odes, (t_eval[0], t_eval[-1]), y0,
                        t_eval=t_eval, method="LSODA", rtol=1e-8, atol=1e-10)
        return {"Cp": sol.y[0] if sol.success else np.full_like(t_eval, np.nan)}

    def odes(self, t, y):
        Cp, Ct, R, DR = y
        binding = self.kon * Cp * R - self.koff * DR
        return np.array([
            -self.CL * Cp / self.Vp - self.Q * (Cp - Ct / self.Kp) / self.Vp - binding + self.kint * DR / self.Vp,
            self.Q * (Cp - Ct / self.Kp) / self.Vt,
            -binding + self.kint * DR - self.kdeg * R,
            binding - self.kint * DR,
        ])

Diagnóstico Hill (Python)

"""
hill_degeneracy.py — Diagnostic protocol for K-n_H degeneracy in the Hill equation.

Author: David Ferrandez Canalis — Agencia RONIN
License: CC BY-NC-SA 4.0 + Cláusula Comercial Ronin
"""

import numpy as np
from scipy.stats import pearsonr


def detect_degeneracy(omega, y, min_points=6):
    """Detect K-n_H degeneracy from (omega, y) data."""
    mask = (omega > 0) & (y > 0)
    omega, y = omega[mask], y[mask]

    if len(omega) < min_points:
        return {"regime": "unknown", "recommendation": "Insufficient data."}

    log_o = np.log(omega)
    log_y = np.log(y)
    slope, intercept = np.polyfit(log_o, log_y, 1)
    residuals = log_y - (slope * log_o + intercept)
    omega_range = float(np.log10(omega.max() / omega.min()))
    corr, p = pearsonr(residuals, log_o)

    if abs(corr) > 0.3 and p < 0.05:
        return {"regime": "inactive", "K_identifiable": True}
    elif omega_range < 1.5:
        return {"regime": "active", "K_identifiable": False,
                "recommendation": "Report only A = K^(-n_H) and n_H."}
    elif omega_range < 3.0:
        return {"regime": "marginal", "K_identifiable": False}
    else:
        return {"regime": "inactive", "K_identifiable": True}

Data Acquisition

"""
data_acquisition.py — Download PK-DB, HCTZ, Bosentan, Theophylline, CvTdb.

Author: David Ferrandez Canalis — Agencia RONIN
"""

import requests
from pathlib import Path

DATA_DIR = Path("data")
DATA_DIR.mkdir(exist_ok=True)

HCTZ_MODEL_URL = "https://github.com/matthiaskoenig/hctz-model/archive/refs/heads/main.zip"
PKDB_BASE = "https://pk-db.com/api/v1"

def download_pkdb_studies(max_pages=3):
    """Download study list from PK-DB."""
    all_studies = []
    for page in range(1, max_pages + 1):
        resp = requests.get(f"{PKDB_BASE}/studies/",
                            params={"page": page}, timeout=15)
        data = resp.json()
        studies = data.get('data', {}).get('data', [])
        if not studies:
            break
        all_studies.extend(studies)
    return all_studies
